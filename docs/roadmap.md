# Roadmap

## MVP

- Local config and SQLite memory.
- Project health scanner.
- Risk scanner for working-tree and release-readiness signals.
- Security scanner wrapper with built-in secret hygiene.
- Rule-based explanations.
- Dry-run and backed-up safe fixes.
- Fix registry with preview, apply, and rollback.
- Command firewall with history.
- JSON/Markdown reporting and CI gates.
- Commit message suggestions.
- Textual dashboard with tabs.

## Near Term

- More fix classes with validation hooks.
- Better Python and Node dependency analysis.
- SARIF export for CI.
- Configurable ignored paths.
- More Textual workflows.

## Later

- Local embedding memory.
- Policy packs for teams.
- Plugin system for custom scanners.
- IDE integrations.
- CI bot mode with strict non-mutating defaults.
